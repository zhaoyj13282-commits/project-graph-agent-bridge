# Validation scope

The bridge has been validated on Windows x64 against the pinned official runtime in `runtime-manifest.json`.

Checks cover the CLI subprocess protocol, strict project aliases and permissions, standard MCP handshake, create/edit/connect/delete/layout with fresh reads, and GUI edits read back through the CLI. Open-project changes require a GUI save before disk persistence is claimed.

Public regression tests use only `tests/fixtures/public.prg` or disposable copies. Machine-specific traces, personal graphs, file hashes and local configuration are excluded from this repository. Platform and release limitations are tracked in `docs/COMPATIBILITY.md`.
