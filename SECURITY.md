# Security reports

For a vulnerability, avoid posting credentials, private graphs or an exploit against someone else's data. Use the repository's private vulnerability reporting feature if available. Otherwise open an issue containing only a short, non-sensitive description and ask the maintainer for a private channel.

Project aliases and allowed roots are authorization boundaries. Destructive operations require both write and destructive permissions. Stdio is local; remote MCP authentication is outside this release. A timeout can leave an open project modified, so inspect before retrying.
